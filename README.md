Neon Shore is an offline web app that turns any photo and a caption into GTA 6-style poster cover art: a multi-panel layout, bold display lettering with a neon script subtitle, and a Vice City sunset or neon colour grade, exported as a PNG in 1080 x 1080, 1080 x 1350 or 1920 x 1080. Pick one of three layouts (hero with three small panels, a 2 x 2 grid, or one full-bleed photo), fill each panel with the same photo or different ones, drag to reposition and zoom each photo, choose one of three colour grades, type your caption, and download the cover in one click. Everything runs in the browser from static files — photos are read on your own machine and never uploaded. Two sample photos are included so the editor is never empty, and the Anton and Pacifico fonts are vendored under the SIL Open Font License.

## Run it

```sh
python3 -m http.server 8080 --directory app
```

Then open http://localhost:8080 in desktop Chrome. No build step, no network requests, no account.
